# TacticalGrid

Juego táctico 2D con búsqueda y toma de decisiones adversariales.

## Proyecto

Proyecto 1 - Sistemas Inteligentes I (UCALDAS)

## Descripción

TacticalGrid es un sistema inteligente que controla dos bandos en un juego táctico bidimensional. Los bandos compiten por alcanzar y transportar un recurso estratégico.

## Fases del Proyecto

1. **Búsqueda No Informada** (BFS, DFS)
2. **Búsqueda con Costos** (UCS)
3. **Búsqueda Informada** (A*)
4. **Búsqueda con Memoria Limitada** (Beam Search)
5. **Decisión Adversarial** (Minimax)
6. **Optimización con Poda Alfa-Beta**
